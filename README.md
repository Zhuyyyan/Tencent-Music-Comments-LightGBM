## 📖 细化项目介绍 (Detailed Project Overview)

随着数字音乐流媒体平台的生态化演进，网易云音乐、QQ音乐等平台的“评论区”已从单纯的用户留言板蜕变为具备强社交属性的情感共鸣社区。**如何从海量文本中精准挖掘、预测具备破圈潜力的“高赞神评”，对于平台内容推荐、用户留存和舆情监控具有重大的商业价值与学术研究意义。**

本项目遵循标准的数据科学跨行业标准流程（CRISP-DM），深度起底腾讯音乐（TME）互动生态，核心拆解为以下四大纵深模块：

### 1. 自动化多源数据挖掘 (Data Acquisition)
* 针对传统静态数据集缺乏时效性的痛点，独立编写高并发自动化爬虫脚本 (`qq_music.py`)。
* 动态拦截 QQ 音乐热歌榜、飙升榜、新歌榜等多维度榜单的 API 接口，不仅全量抓取歌曲元数据（播放量、MV标识、流派标签），更下钻抓取每首歌曲旗下的真实用户交互评论，**累计清洗并构建了包含 5 万余条真实乐评的全量核心本地数据库**。

### 2. 高维语义工程与特征对齐 (Feature Engineering)
* **统计特征提取**：多维构筑包括评论绝对字数、句子结构复杂度、环境扰动因子（如是否有MV、音乐标签热度编码）以及基于专家词网构建的“粉丝效应得分（Fan-Effect Score）”。
* **NLP高维特征映射**：引入 `jieba` 分词引擎对乐评文本进行柔性切词与无监督停用词清洗，利用 **TF-IDF（词频-逆文档频率）** 算法将清洗后的中文文本映射为高维稀疏特征矩阵（High-Dimensional Sparse Matrix），捕捉隐藏在文本长尾中的关键情绪语义词。

### 3. 可解释集成学习算法建模 (Machine Learning Modeling)
* 选用前沿的 **LightGBM (前沿集成树模型)** 作为核心分类器。得益于其基于直方图的决策树算法及 GOSS（单边梯度采样）技术，模型在处理高维稀疏的 TF-IDF 特征时展现出极高的拟合效率与泛化能力。
* 通过五折交叉验证与超参数网格搜索，最终训练出的 `best_model.pkl` 在测试集上的精度（Precision）与召回率（Recall）均达到优异的学术交付指标。

### 4. 融合人类专家经验的“语义逻辑对冲引擎” (Expert Rule Alignment)
* 单纯的机器学习模型容易受高频水贴、营销打卡等噪声干扰（产生高置信度的误报）。为此，本项目在模型推理后端创新性地架构了 **“语义逻辑对冲引擎”**。
* **机制一（一票否决）**：对命中“一般般、难听、凑热闹”等低共鸣敷衍批判词的评论，实行逻辑降权（原生置信度直接削减 80%）。
* **机制二（长尾情感救援）**：精准捕获“深夜、耳机、眼泪、错过的”等深情长尾词。若同时伴随“纯路人/路人”等中性身份词，系统自动判定为极其稀缺的 **【客观路人真情流露流派】**，保底触发 78% 的神评概率拉伸，完美对冲了纯算法在面对冷启动文本时的机械局限性。

## 🛠️ 系统架构图 (System Architecture)
```text
[输入原始乐评文本] 
       │
       ├───► [数据管道 1] ──► 统计文本长度、提取粉丝狂热指数等统计特征
       └───► [数据管道 2] ──► jieba 柔性分词 ──► 过滤停用词 ──► TF-IDF 词袋矩阵映射
               │
               ▼
       [高维组合特征矩阵 (Aligned Feature Matrix)] 
               │
               ▼
       [LightGBM 前沿集成树模型] ────► 预测出原生置信概率 (Proba)
               │
               ▼
       [📊 语义逻辑对冲纠偏引擎 (Expert Rule Alignment)]
               ├──► 机制一：敷衍/批判语义一票否决制 (置信度骤降 80%)
               ├──► 机制二：客观路人 + 情感长尾提权补偿 (置信度保底拉伸至 78%)
               └──► 机制三：纯工具人打卡流水账动态降权 (置信度适度降低 50%)
               │
               ▼
       [📈 最终校准后置信度 & 1:1 数据大屏看板可视化]
```
